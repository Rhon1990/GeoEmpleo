# Alcampo en TalentForJobs

1. Reutilizar la navegación ASP.NET ya comprobada para Carrefour, parametrizando únicamente el origen y el formulario. Probar paginación, enlaces oficiales y rechazo de duplicados.
2. Leer todas las páginas del tablón oficial de Alcampo y las fichas de cada oferta para obtener descripción y localidad. Solo publicar ofertas que el portal identifica como Alcampo y situar municipios españoles inequívocos.
3. Incorporar el conector al registro y al runner diario, un logotipo oficial local, pruebas de marca y documentación. Validar una captura completa aislada antes de publicar.
4. Ejecutar pruebas, tipos y compilación; comprobar que las nuevas fuentes no sustituyen ofertas existentes ante un fallo parcial. Publicar solo una compilación con catálogo vigente y verificar ambos dominios por HTTPS.
