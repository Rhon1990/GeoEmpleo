# Decathlon en TalentClue

1. Leer el widget TalentClue insertado en la página oficial de Decathlon. Validar cada fila: ID, enlace de TalentClue, empresa, país España, provincia y localidad.
2. Obtener la descripción de cada ficha mediante una redirección limitada al subdominio de Decathlon en TalentClue. Rechazar IDs o títulos contradictorios y conservar la captura anterior si falla alguna ficha.
3. Añadir la fuente al runner diario, el logo oficial local y las pruebas de parser, geografía y marca. Ejecutar una captura aislada completa antes de publicar.
