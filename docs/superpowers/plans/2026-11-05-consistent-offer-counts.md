# Consistent Offer Counts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the same search total on desktop and mobile while explaining which offers can appear on the map.

**Architecture:** Both `/api/jobs` adapters calculate a search total without viewport bounds, a count with valid map points, and the existing viewport total. A small pure presentation function formats those figures. The browser leaves the list and pins scoped to the map as before.

**Tech Stack:** Node.js 24, ES modules, Node test runner, static Firebase Hosting.
