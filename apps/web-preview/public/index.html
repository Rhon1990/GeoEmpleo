Datos reales, sin rellenar los huecos

El catálogo combina una selección verificada de convocatorias BOE con ofertas activas del SEF Murcia actualizadas por un proceso diario. Cada detalle muestra su origen y la fecha en que se comprobó. Los datos no publicados se mantienen desconocidos. Las ofertas sin coordenadas verificadas se muestran en la lista y quedan fuera de los filtros geográficos.

Comprueba las bases antes de solicitar

La publicación del BOE enlaza con las bases de cada proceso. La inscripción se realiza fuera de GeoEmpleo y puede requerir identificación. El plazo se reproduce tal como aparece; no hemos calculado su fecha final ni comprobado posibles cambios posteriores.

Un mapa conectado con las convocatorias

Al abrir la página, el navegador solicita permiso para situarte. La posición se usa una sola vez y no se guarda. Google Maps recibe el centro y el área visible para dibujar el mapa; GeoEmpleo consulta esa área para devolver solo ofertas cercanas. La lista se actualiza al terminar cada movimiento, sin seguimiento continuo ni recrear el mapa. Puedes denegar el permiso y elegir una localidad. Las ubicaciones de ofertas son municipales, no direcciones exactas.
